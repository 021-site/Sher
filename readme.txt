گنجینه حافظ و سعدی - صدرا - راهنمای گیت‌هاب بدون خطای 404
1- یک ریپو Public بساز مثلا hafez-saadi
2- هر 3 فایل index.html و style.css و script.js را جدا آپلود کن در روت (داخل پوشه نذار)
3- اسم‌ها دقیقا با حروف کوچک باشد: index.html
4- Settings > Pages > Deploy from a branch > Branch: main > /(root) > Save
5- یک دقیقه صبر کن بعد باز کن: https://username.github.io/hafez-saadi/
علت 404 قبلی: تک فایل داخل پوشه یا اسم با حرف بزرگ بود. این نسخه لینک‌ها relative است: style.css و script.js
